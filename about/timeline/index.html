    Previous work

    2013-08

    - Blog post by Robin Wilson: "Introducing CITATION files"

    Initial idea and community discussion

    2017-09

    - WSSSPE5.1 Lightning talk by Stephan Druskat: "Should CITATION files be standardized?"
    - Breakout group discussion outlines initial requirements (blog post)

    Citation File Format 1.0.0

    2017-12

    - Citation File Format 1.0.0 released

    Community growth and initial tools

    2018

    - 2018-02: Rob Haines releases the first version of ruby-cff
    - 2018-05: Jurriaan Spaaks releases cffconvert 1.0.0
    - 2018-09: CFF Hack Day at RSECon2018 (Birmingham, UK): 26 participants collaborate on 11 projects
    - 2018-10: Jurriaan Spaaks joins the project as co-lead

    Citation File Format 1.1.0

    2021-05

    - Citation File Format 1.1.0 released
    - First version with a validation schema

    Integration with platforms

    2021-07

    - Stephan, Jurriaan and Rob collaborate with GitHub for their support for software citation, launched 2021-07-21
    - 2012-07-22: Zenodo announces support for reading metadata from CITATION.cff files
    - 2012-07-22: Zotero reads metadata from CITATION.cff on GitHub pages - 2012-07-22: JabRef can import and export CITATION.cff files

    Citation File Format 1.2.0

    2021-08

    - Citation File Format 1.2.0 released
    - Implemented as JSON Schema
    - Integration with IDEs through schemastore.org

    10,000 GitHub repositories have added a CITATION.cff file
