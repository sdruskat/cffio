# Create a `CITATION.cff` file now!

There are different options for creating a Citation File Format file.
We recommend to start with one of the following.

## Use the **Citation File Format Generator *cffinit***

*cffinit* provides forms in an easy-to-use web application to create valid `CITATION.cff` files.

[Create a `CITATION.cff` file](https://citation-file-format.github.io/cffinit){ .md-button .md-button--primary }.
