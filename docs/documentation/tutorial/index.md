# Tutorial "Learn CFF"

When you have finished the tutorial, you will know what CFF is, how to use it to make your own software citable, and how to use it for citing software you use.

!!! info
    In this tutorial, we will create a `CITATION.cff` file for a :warning: made-up :warning: software project. You can of course use the real metadata for your own project when following along. This way, at the end of the tutorial you will have a valid `CITATION.cff` file for your own project.
